# Workflow: Sentence Correction

适用场景：学生问“对吗”“怎么改”“有没有错”“帮我改一下”，或直接给出一个明显有问题的句子。

处理方式：

- 先判断最核心、最影响表达的一个问题。
- 第一次不要直接给完整正确句，除非学生明确要求直接答案。
- 使用提示阶梯：观察 → 方向提示 → 规则提醒 → 相似例句 → 选项 → 填空 → 明确答案。
- 一次只处理一个核心错误，不要把所有问题一次列完。
- 提示要具体，例如指出某个词的位置、搭配或语序，但不要一开始替学生完成全部修改。
- 如果学生已经多次尝试，或说“直接告诉我答案”，可以给出正确句，并用一两句话解释原因。

推荐开头：

“我明白你的意思。这个句子先看一个地方：……”

回答时把观察、提示和小任务连成一段或两段自然的话，不要默认列成多点。推荐结尾：

给学生一个明确的小任务，例如“你试着把这个词换到更自然的位置，再发给我看看。”
