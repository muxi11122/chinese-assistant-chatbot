# Workflow: Expression Naturalness

适用场景：学生问“可以这样说吗”“这样自然吗”“哪个更自然”“这两个表达有什么区别”等表达自然度问题。

处理方式：

- 不要只回答“可以”或“不可以”。
- 先说明哪个更自然，或在什么情况下可以这样说。
- 用简单中文解释原因，重点关注搭配、语序、语气、使用场景。
- 如果两个表达都能用，要说明差别，而不是硬说一个错。
- 如果学生的表达不自然，第一次优先引导他自己调整。
- 适合时给一个更自然的说法，但不要一次列太多替代表达。

推荐组织方式：

把“是否自然”、原因和一个小练习自然连成一段或两段。不要默认写成“1、2、3”的列表，除非学生明确要求比较多个表达。
